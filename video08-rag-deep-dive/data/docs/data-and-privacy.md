# Data and privacy

## Exporting your data
A workspace admin can export all workspace data at any time from Settings, then Export. The export is a single ZIP file of JSON documents and is emailed to the admin within an hour.

## Data retention after cancellation
When a workspace is cancelled, its data is kept for 90 days so the customer can change their mind or export it. After 90 days, the data is permanently deleted and cannot be recovered.

## Data residency
Customer data is hosted in the EU (Frankfurt) or the US (Virginia). The region is chosen when the workspace is created and cannot be changed later.
